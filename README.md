# Cuidando-Huellita
Sistema web desarrollado para la gestión integral de un refugio de animales, facilitando el control de registros y adopciones.

# Tecnologías utilizadas
* Lenguaje: HTML, CSS y PHP.
* Base de datos: PostgreSQL.
* Herramientas: Visual Studio Code.

# Funcionalidades principales
* Registro de mascotas en el refugio.
* Interfaz intuitiva para la gestión de datos.
* Adoptar mascotas y darles una mejor vida.
* Donar al refugio: (Dinero, comida, juguetes y ropa).
* Denunciar cualquier maltrato hacia una mascota.
